# Longhorn Messenger

Мессенджер в стиле Windows Longhorn / iOS 6: стеклянный UI, глянцевые аватарки, звонки.

## Состав

```
server/          Go-бэкенд (REST + WebSocket + WebRTC-сигналинг), только stdlib
ui/              Фронтенд: index.html + app.js (ванильный JS, без сборки)
src-tauri/       Tauri 2 обёртка (кастомный тайтлбар, иконки)
test/e2e.js      Интеграционные тесты против живого сервера
PROTOCOL.md      Контракт протокола сервер↔клиент
```

## Быстрый старт (два терминала)

```bash
# 1) Сервер
cd server
go run . -addr :8080 -db data/db.json -seed

# 2) Фронтенд — в браузере (для разработки)
npx -y http-server ui -p 8091
# открыть http://127.0.0.1:8091
```

Демо-аккаунты (при `-seed`): **Алиса, Дима Билд, Хук-хук, Сергей, Катя** — пароль `demo1234`, плюс **Эхо-бот** (всегда в сети, отвечает на всё, звонки отклоняет «занят»).

## Tauri (десктоп)

```bash
npm i -D @tauri-apps/cli
npx tauri dev        # дев-режим
npx tauri build      # релиз: src-tauri/target/release/bundle/{nsis,msi}
```

Сервер при этом должен быть запущен (адрес вводится на экране входа, по умолчанию `http://localhost:8080`).

## Тесты

```bash
# unit-тесты сервера
cd server && go test ./...

# e2e против живого сервера
go run . -addr :8080 -db /tmp/e2e.json -seed &   # или любая пустая база
node ../test/e2e.js
```

## Возможности

- Регистрация/логин, присутствие как в Discord: `В сети / Неактивен (авто-idle 5 мин) / Не беспокоить / Невидимка`, «был(а) N мин. назад»
- Личные сообщения с `✓ доставлено` / `✓✓ прочитано`, «печатает…», оффлайн-доставка, счётчики непрочитанного, история с подгрузкой вверх
- Эмодзи-пикер (глянцевые SVG) + текстовые шорткаты `:)` `:D` `<3` и `:smile:`
- Звонки WebRTC (аудио, STUN), full-screen UI + мини-пилюля, mute, reject/cancel/busy
- **Звонок оффлайн-юзеру**: звонок встаёт в очередь, у него зазвонит при входе в сеть; не ответил 45 с → «Пропущенный звонок» в чате
- Тёмная/светлая тема, тосты, звуковые сигналы, реконнект с экспоненциальной задержкой
- Служебные события звонков пишутся в историю чата

## Прод

Развёрнуто на `ngmusic` (SSH-хост из `~/.ssh/config`):

- **https://lh.g2961.space** — публичный адрес (HTTPS, Let's Encrypt; UI + API + WSS через Caddy)
- Важно: микрофон/звонки работают только по HTTPS (secure context) — поэтому домен, а не голый IP
- Go-сервер: systemd-юнит `longhorn-server.service`, порт `127.0.0.1:8092`, база `/var/lib/longhorn/db.json`, демо-юзеры засеяны
- Файлы: `/srv/longhorn/` (бинарник + `ui/`)
- Caddy-блок `lh.g2961.space` в `/etc/caddy/Caddyfile` (бэкап старого конфига: `Caddyfile.bak-longhorn`); статика — `Cache-Control: no-cache`
- Обновление: пересобрать `GOOS=linux GOARCH=amd64 go build` → `scp` бинарника и `ui/*` → `systemctl restart longhorn-server`
- HTTP-порт :8082 был временным — удалён после переезда на домен

## Что по чему

- `server/hub.go` — маршрутизация WS-кадров, звонковая семантика, очередь
- `server/store.go` — JSON-хранилище (атомарная запись), пароли salt+sha256
- `server/ws.go` — самописный WebSocket RFC 6455 (без зависимостей)
- `ui/app.js` — весь клиент: рендер, WS, WebRTC, presence, idle-детектор
- `src-tauri/` — конфиг окна, capabilities, `connect_server`
